# LiveRetail Webs

Redesign of [liveretailwebs.com](https://liveretailwebs.com) — a static portfolio for the Indore web studio.

## Run locally

Open `index.html`, or:

```bash
python3 -m http.server 8080
```

## Deploy

GitHub Pages: Settings → Pages → Deploy from branch `main` / root.

Point the `liveretailwebs.com` DNS at the Pages host (or another static host) when you are ready to replace the live site.
